# Wasserversorgung St. Ruprecht – PWA

## Veröffentlichung mit GitHub und Vercel
1. ZIP-Datei entpacken.
2. Auf GitHub ein neues Repository `wasser-st-ruprecht` anlegen.
3. Alle Dateien aus diesem Ordner hochladen und committen.
4. Bei Vercel anmelden, **Add New > Project** wählen und das GitHub-Repository importieren.
5. Framework Preset: **Other**. Build Command leer lassen. Output Directory `.`.
6. **Deploy** klicken.
7. Die erzeugte HTTPS-Adresse auf dem Smartphone öffnen und zum Home-Bildschirm hinzufügen.

## Hinweise
- Kein Build-Schritt nötig: reine HTML/CSS/JavaScript-PWA.
- Daten werden lokal im Browser gespeichert.
- Vor Gerätewechsel ein JSON-Backup exportieren.
- Zwei Einträge am 20.08.2026 führen chronologisch zu unplausiblen Zählerfolgen und werden orange markiert.
